## 0. Короткий ответ на ваш вопрос про рекламу

**Нет, стоимость рекламы выставлять не нужно и невозможно.** Реклама (interstitial и rewarded через
`VKWebAppShowNativeAds`) — бесплатна для игрока, её цену и выплату вам определяет VK. Модератор про
рекламу вообще не писал. Замечание относится к кнопке **«Магазин»**, где мы продаём кусочки фигурки
за голоса через `VKWebAppShowOrderBox`. Именно там: (а) окно покупки не открывается / выдаёт ошибку,
(б) в интерфейсе магазина не написано, сколько голосов стоит каждый товар.

## 1. Почему «платежи не работают» — техническая причина

Платёжная система голосов VK устроена так:

1. Игра вызывает `VKWebAppShowOrderBox({type:'item', item:'factbum_piece_1'})`.
2. **VK обращается на ваш сервер** («Адрес обратного вызова» в настройках приложения → Платежи)
   с уведомлением `get_item` и ждёт ответ `{title, price (в голосах), item_id, photo_url}` —
   только из этого ответа VK берёт цену и название для окна покупки.
3. После подтверждения игроком VK снова обращается к серверу — `order_status_change`
   (`status=chargeable`), сервер должен ответить «заказ проведён», тогда голоса списываются.
4. Все уведомления подписаны секретным ключом приложения (`sig`), сервер обязан проверять подпись.

**У нас статическая игра без сервера** (VK Pages hosting отдаёт только файлы). Адрес обратного
вызова не задан → на шаге 2 VK не получает цену → окно покупки показывает ошибку. Товары
`factbum_piece_1 / _5 / factbum_figure_any` в кабинете не «создаются» списком — VK их не хранит,
он спрашивает о них ваш сервер каждый раз. Поэтому одно только создание «товаров» в настройках
проблему не решило бы.

Вывод: **платежи голосами в принципе невозможны без собственного HTTPS-сервера.**

## 2. Два пути. Рекомендация — путь A

### Путь A (рекомендую): убрать магазин, оставить монетизацию только рекламой — версия 1.47

Это соответствует вашей исходной установке («игра бесплатна, монетизация только через рекламу
VK») и снимает замечание №1 полностью, без сервера и без затрат.

Что меняется в игре:
- Убрать кнопку **«Магазин»** с главного экрана и экран `scr-shop`; убрать вызовы
  `VKWebAppShowOrderBox` / `VKWebAppGetPurchases` и тексты `shop_*` (RU/EN).
- Оставить и сделать заметнее «**Случайный фрагмент за просмотр рекламы**» (rewarded) — это
  единственный «платный» способ ускорить сборку фигурки, и он бесплатен для игрока.
- Всё остальное (interstitial после партии, облачное сохранение, справка с вашим текстом) — без
  изменений. Версия везде «1.47».
- В кабинете VK: раздел **Платежи** оставить выключенным/пустым, «Адрес обратного вызова» не
  заполнять. Товары в описании/скриншотах не упоминать.

Комментарий модератору при переподаче (пример):
> «Внутриигровые покупки удалены полностью. Игра бесплатна, монетизация только через рекламу VK
> (interstitial после партии и rewarded-ролик за фрагмент фигурки). К приложению привязано
> сообщество для обратной связи.»

### Путь B (если магазин принципиально нужен): поднять платёжный сервер — версия 1.48+

Понадобится:
1. **HTTPS-endpoint** (Node/Python, ~80 строк) на любом хостинге: VK Cloud Functions, Timeweb
   Cloud, Selectel, дешёвый VPS. Обрабатывает `get_item` → отвечает
   `{"response":{"title":"1 кусочек пазла","price":3,"item_id":"factbum_piece_1","expiration":86400}}`;
   `order_status_change` со `status=chargeable` → отвечает
   `{"response":{"order_id":<id>,"app_order_id":<ваш id>}}`; `status=refunded` → подтверждает
   возврат. Проверяет `sig` = md5 отсортированных параметров + секрет приложения.
2. В кабинете: Платежи → Адрес обратного вызова = ваш URL; включить тестовый режим и добавить
   себя в «Тестеры платежей»; провести тестовую покупку; затем выключить тестовый режим.
3. **В интерфейсе магазина явно написать цену каждого товара в голосах**, например
   «1 кусочек — 3 голоса», «5 кусочков — 12 голосов», «Фигурка целиком — 20 голосов», плюс
   строку «1 голос ≈ 7 ₽» (курс уточнить в кабинете). Цены в UI должны совпадать с ответом
   сервера — это и есть замечание «стоимость должна быть явно указана».
4. Нюанс: у нас нет серверного хранения прогресса — выдача товара идёт на клиенте после
   успешного ответа `VKWebAppShowOrderBox`, а сервер лишь подтверждает заказ. Это допустимо для
   VK, но при сбоях клиента игрок может остаться без товара → нужна кнопка «Восстановить покупки»
   (`VKWebAppGetPurchases`), она у нас есть.

Стоимость пути B — сервер (от ~150–300 ₽/мес или бесплатный тариф функций), поддержка, обработка
возвратов и споров. Для игры с бесплатной моделью это лишняя нагрузка — поэтому A.

## 3. Замечание №2 — сообщество: зачем, как создать, как должно работать

### Зачем
- В карточке приложения VK показывает «Разработчик/Сообщество». Если указана личная страница —
  игроки пишут вам в личку; закрытые ЛС = «нет канала связи» → модерация отклоняет.
- Сообщество даёт: единый ящик обращений (можно назначить модераторов), стену для новостей о
  версиях, раздел «Обсуждения» (FAQ, баги, предложения), статистику, возможность добавить игру
  кнопкой прямо в меню сообщества и запускать рекламу/посты с кнопкой «Играть».
- Модерация VK явно предпочитает сообщество: у них есть требование «доступный канал связи», и
  сообщество с открытыми сообщениями его закрывает на 100 %.

### Как создать (10–15 минут)
1. vk.com → слева **«Сообщества»** → **«Создать сообщество»** → тип **«Бренд или организация»**
   (либо «Тематическое сообщество») → название `Факт-бум. Кто ты?`, тематика «Игры» →
   Создать.
2. **Управление → Настройки → Основная информация:** описание (2–3 предложения: что за игра,
   что «10 тем, 1000 фактов, собери фигурку»), короткий адрес (например `factboom_game`),
   обложка (можно взять `snippet-1120x630.png` — VK обрежет под 1590×400, лучше сделать отдельную
   1590×400), аватар — `assets/ui/logo-512.png`.
3. **Управление → Сообщения:** включить «Сообщения сообщества». Настроить приветствие:
   «Привет! Это поддержка игры «Факт-бум. Кто ты?». Опишите проблему и укажите, с какого
   устройства играете — ответим в течение суток.» Включить кнопку «Написать» на главной.
4. **Управление → Разделы:** включить «Обсуждения» (создать темы «Ошибки и баги»,
   «Предложения», «Вопросы по игре»), «Ссылки» (ссылка на vk.com/app54741087).
5. **Управление → Приложения (Меню)**: добавить мини-приложение 54741087 — у сообщества появится
   кнопка запуска игры.
6. Первый пост на стену: анонс игры + кнопка/ссылка на приложение (закрепить).
7. **Управление → Участники → Руководители:** при желании назначить помощника-модератора,
   чтобы отвечал на сообщения.

### Как привязать к приложению
- **dev.vk.com → Мои приложения → 54741087 → Настройки → Информация** (раздел с
  описанием): поле **«Сообщество»** (может называться «Группа приложения»/«Связанное сообщество»)
  — выбрать созданное сообщество и сохранить. Там же поле «Ссылка на поддержку/e-mail
  разработчика» — укажите `https://vk.me/<короткий_адрес_сообщества>` (прямая ссылка на диалог).
- Вы должны быть владельцем/администратором и приложения, и сообщества с одного аккаунта.
- После привязки в карточке приложения вместо вашей страницы отображается сообщество.

### Как оно должно работать дальше (минимум без «воды»)
- **Отвечать на входящие сообщения** в разумный срок (VK показывает «обычно отвечает за N»).
  Шаблоны ответов: «сохранение», «не показывается реклама/не начислен фрагмент», «как собрать
  фигурку».
- **Пост при каждом релизе** (1–3 строки: что нового) — модерация и игроки видят, что проект
  живой.
- Раз в неделю смотреть «Обсуждения → Ошибки» и «Сообщения».
- Не обязательно набирать подписчиков — для модерации важна доступность канала, а не размер.

### Альтернатива (если совсем не хотите сообщество)
Настройки страницы → Приватность → «Кто может писать мне личные сообщения» → **Все**.
Формально удовлетворяет замечанию, но все обращения пойдут в личку; модератор явно написал
«рекомендуем сообщество», поэтому лучше сделать сообщество.
