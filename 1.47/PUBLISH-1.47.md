# Публикация «Факт-бум. Кто ты?» 1.47 на VK Mini Apps hosting

**Подробная пошаговая инструкция.** Мы выкладываем папку с игрой на официальный
хостинг VK Mini Apps (страницы `*.pages.vk-apps.ru`) одной командой. Нигде
сторонний хостинг не используется. После деплоя адрес приложения
`vk.com/app54741087` будет отдавать версию 1.47. Старую опубликованную 1.44
**удалять не нужно** — новый деплой просто обновит адрес приложения (см.
раздел «Что происходит со старой 1.44»).

Время: ~20 минут. Нужно: компьютер с Windows (или Mac/Linux), интернет, файл
**`factbum-vk-miniapps-1.47.zip`**.

> Не путайте: **VK Play** — это магазин полноценных игр (exe-файлы), а у нас
> **VK Mini Apps** — веб-игра, которая запускается внутри VK. Инструмент
> публикации — `@vkontakte/vk-miniapps-deploy` (именно для Mini Apps).

---

## Шаг 1. Установить Node.js (только если ещё не стоит)

Node.js — программа, которой выполняется команда публикации.

1. Проверьте, стоит ли она: откройте командную строку (см. Шаг 3, она нужна
   будет в любом случае) и введите:
   ```
   node -v
   ```
   - Если ответ вида `v20.11.0` (любая версия v16 или выше) — **переходите к Шагу 2**.
   - Если «не является внутренней или внешней командой» (или похожее) — ставим:
2. Откройте браузер и перейдите на **https://nodejs.org** — нажмите большую
   кнопку **LTS** (Recommended for most users) и скачайте файл.
3. Запустите скачанный установщик: все кнопки по умолчанию **Next → Next →
   Install → Finish** (ничего дополнительно отмечать не нужно).
4. **Закройте и заново откройте** командную строку (важно!) и снова введите
   `node -v` — теперь должна появиться версия.

## Шаг 2. Распаковать архив

1. Найдите файл **`factbum-vk-miniapps-1.47.zip`**.
2. ПКМ по нему → **Извлечь всё… (Extract All…)** → выберите папку →
   **Извлечь**.
3. **Важно — путь к папке должен быть коротким, без пробелов и кириллицы.**
   Хороший пример:
   ```
   C:\factboom\fact-boom-vk-1.47
   ```
   Плохие: `C:\Users\Вася\Pictures\Мои игры (1)\fact-boom-vk-1.47` — пробелы,
   скобки и кириллица в пути ломают команду. Если так — просто переместите
   папку в `C:\factboom\`.
4. Загляните внутрь: в папке `fact-boom-vk-1.47` должны лежать
   `index.html`, `vk-hosting-config.json`, `manifest.webmanifest` и папки
   `css`, `js`, `data`, `assets`. Если видите что-то вроде `readme` или
   `server.js` — это не тот архив.

В файле `vk-hosting-config.json` уже всё настроено (в том числе
`"app_id": 54741087`) — менять ничего не нужно. Если хотите убедиться:
откройте его в Блокноте, там строка `"app_id": 54741087`.

## Шаг 3. Открыть командную строку прямо в папке с игрой

Команда публикации должна выполняться **внутри** папки `fact-boom-vk-1.47`.
Самый простой способ без ручного ввода пути:

1. Откройте папку `C:\factboom\fact-boom-vk-1.47` в **Проводнике** (тот, где
   видно index.html и папки css/js/…).
2. Кликните мышью в **строку адреса** сверху окна (там, где написан путь),
   и старое содержимое выделится.
3. Просто наберите `cmd` и нажмите **Enter**.

Откроется чёрное окно командной строки — и оно уже находится в нужной папке.

Проверка: введите
```
dir
```
и нажмите Enter — в списке должны быть `index.html` и `vk-hosting-config.json`.

*Другой способ (если не хочется кликать по строке адреса): нажмите
**Win + R**, введите `cmd`, Enter. Затем введите путь к папке со словом `cd`:
```
cd /d C:\factboom\fact-boom-vk-1.47
```
(подставьте свой путь) и Enter.*

## Шаг 4. Выполнить команду публикации

В том же чёрном окне введите (можно скопировать-вставить мышью — клик по
правому краю окна позволяет вставлять) и нажмите **Enter**:

```
npx @vkontakte/vk-miniapps-deploy
```

Что произойдёт:

- `npx` — встроенный в Node.js механизм: он сам скачает официальный
  инструмент VK `@vkontakte/vk-miniapps-deploy` и запустит его.
- При **первом** запуске будет строка вида
  `Need to install the following packages: @vkontakte/vk-miniapps-deploy@1.0.2`
  и вопрос `Ok to proceed? (y)` — нажмите **y** и Enter.
- Скачивание и запуск могут занять 1–3 минуты — окно будет молчать, это
  нормально, не закрывайте его.

## Шаг 5. Ответить на вопросы в консоли

Инструмент задаёт вопросы **по одному** прямо в консоли. Для каждого ответа
набираете текст и нажимаете Enter. Если по умолчанию предложен `yes` (выделен),
можно просто нажать Enter — это то же самое, что «yes».

| Вопрос в консоли | Ответ |
|---|---|
| `Would you like to deploy to VK Mini Apps hosting using these commands?` | **yes** (или просто Enter) |
| `Would you like to update prod urls?` | **yes** — ⚠️ самый важный ответ: именно он указывает адрес приложения на новую сборку |
| `Would you like to update dev urls?` | **yes** |
| `Would you like to update test group url?` | **no** (наберите no; по умолчанию и так no) |

## Шаг 6. Войти в VK по ссылкам (два раза)

Дальше консоль покажет строчку вида:

```
Please open this url in browser https://oauth.vk.com/code_auth?state=check&code=…&revoke=1
```

Это надо повторить **дважды** (ссылки будут две, по очереди):

1. В консоли **выделите мышью всю ссылку** (от `https://` до конца строки),
   нажмите **Ctrl+C** — скопировалось.
2. Откройте браузер (Chrome/Edge/что угодно), вставьте ссылку в адресную
   строку, Enter.
3. Войдите в свой аккаунт VK (тот, которому принадлежит приложение
   54741087) и **разрешите доступ**, если страница попросит.
4. Вернитесь в окно консоли и **нажмите Enter** (консоль в это время ждёт
   именно подтверждения — она не понимает сама, что вы открыли ссылку).

В консоли появится строчка **`Is saved to your CI token!`** — значит, вход
успешный. Повторите шаги 1–4 для второй ссылки.

## Шаг 7. Подтвердить деплой с телефона

Консоль покажет:

```
Please, confirm deploy on your phone.
```

- На **телефон** владельцу приложения придёт сообщение в VK (от разработчика /
  в сообщении «Разработчикам» — тому аккаунту, которому принадлежит приложение
  54741087).
- Откройте его и **подтвердите деплой**.
- После подтверждения в консоли появятся три новых адреса:
  `vk.ru`, `iOS & Android`, `m.vk.ru` (пример:
  `https://…54741087-xxxxxxxx.pages.vk-apps.ru/index.html`).

## Шаг 8. Проверить приложение

1. Откройте страницу «Отображение» приложения:
   **https://dev.vk.com/ru/admin/app-settings/54741087/display**
   Проверьте: три HTTPS-адреса прописаны, название и иконка приложения
   правильные.
2. Откройте в браузере **https://vk.com/app54741087** — игра должна
   загрузиться; версия 1.47 видна на главном экране (мелкая надпись «версия
   1.47»).
3. Сыграйте партию. Проверьте:
   - кнопка «…за просмотр рекламы» на главном экране (на телефоне VK ролик
     должен показываться, кусочек — начисляться);
   - после партии — полноэкранная реклама (interstitial, на телефоне VK);
   - кнопка «Магазин» — в приложении VK статус «Оплата доступна».

## Что происходит со старой 1.44

**Удалять ничего не нужно.** Команда загрузила новую ревизию страницы на
хостинг VK, а ответ «yes» на `update prod urls` обновил производственный
адрес приложения: `vk.com/app54741087` сразу отдаёт 1.47. Прежняя сборка
осталась на хостинге старой ревизией и больше нигде не используется —
ручная зачистка не требуется. Если в новой ссылке другой хэш
(например, `…-9ac2c366d624.pages.vk-apps.ru` сменился на
`…-новый.pages.vk-apps.ru`) — это нормально: каждая ревизия получает свою
страницу, а приложение указывает на последнюю.

## Файл build.zip

После успешного деплоя в папке появится файл **`build.zip`** — это сам
архив, который улетел на хостинг. Его можно удалить, на игру он не влияет.

## Если что-то пошло не так

- **`User authorization failed: invalid session`** — инструмент «забыл»
  авторизацию. Удалите файл
  `%USERPROFILE%\.config\configstore\@vkontakte\vk-miniapps-deploy.json`
  (папки `.config` и `.configstore` скрытые: в Проводнике включите
  «Вид → Показ → Скрытые элементы», либо вставьте этот путь в строку адреса
  Проводителя и удалите файл) — затем выполните команду из **Шага 4** заново.
- **Консоль молчит дольше 3–5 минут** после команды — закройте и запустите
  заново (Шаг 4), ответьте на вопросы снова.
- **Любая другая ошибка** — пришлите точный текст ошибки (снимок окна или
  копией) и последние ~15 строк консоли: разберём по тексту.
